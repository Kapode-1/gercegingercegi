# Tayyip Minsin — The Policy Atlas V2

## Yerel önizleme
`index.html` dosyasına çift tıklayın. Tüm yollar yerel açılışa uyumludur.
Daha güvenilir test için klasörde `python -m http.server 8080` çalıştırıp `http://localhost:8080` adresini açın.

## Hazır modüller
- Sinematik giriş sekansı ve canlı İstanbul saati
- Canvas tabanlı enerji/diplomasi rotaları
- Etkileşimli araştırma atlası
- Policy Brief dosya sistemi
- Diplomatik kayıt zaman çizgisi
- Mobil kırılımlar ve reduced-motion desteği
- Decap CMS içerik şeması
- SEO ve güvenlik başlıkları
